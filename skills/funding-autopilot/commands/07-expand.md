# /expand — Strengthen the profile without exaggeration

1. Start from the actual uploaded CV and user-approved `private/profile.json`. Scan named public repos, publication pages, academic profiles and permitted reference documents already provided/linked by the applicant. Do not independently collect sensitive data.
2. For each discovered result distinguish **direct source fact**, **credible implication**, **unverified inference**, and **proposed future work**. A GitHub README does not prove a software system's external adoption, performance claims, or that the applicant solely authored everything in the repo.
3. Suggest only additive, uniquely sourced profile facts. Provide the quoted research contribution, source URL/document locator and whether it should appear in a fellowship independence statement, proposed research impact or preliminary results.
4. Present proposed changes before writing to the applicant's private profile. Require approval for inferred authorship/leadership or research impact. Never rewrite or embellish an external CV automatically.
5. Record approved facts with date, source/version and supporting evidence; review and reconcile clashes with the original CV.

Outcome: stronger **evidence**, not inflated accomplishments.
