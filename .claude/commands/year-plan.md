# /year-plan — One year of verified research-funding preparation

Run the yearly planning method in `skills/funding-autopilot/commands/09-year-plan.md`. Use the user's private, uploaded-CV-backed profile, funding ledger, career status and location. In `$ARGUMENTS` the user may supply a start month or a focus area.

Generate a **real, personalized 12-month research funding plan** at `private/annual-plan.md`, not just a prose suggestion or the public illustration. Work month by month from verified scheme deadlines and institutional cutoffs. Separate ongoing CV/research evidence, official opportunity discovery, independent-vs-new-PI hosting, Prepare experimental/funding argument, Apply reviewing and Track recorded outcomes.

If a grant has no verified current-round deadline, label it unknown and create a **verification task**, never a fictitious scheduled deadline. Include multiple parallel routes only if relevant and affordable to the applicant. Use `docs/PROPOSAL-STRATEGIES.md` for independent fellowships, PI-led projects, collaborative consortia, innovation grants and impact awards.

State in the result: **"Plan generated; no unattended monitoring or reminders created."** Never automatically send emails, funder forms or applicant documents.
